--------------------------------------------------------------------------------
1. ARCHIVOS CREADOS EN EL PROYECTO
--------------------------------------------------------------------------------
• index.html
  - Interfaz de Usuario interactiva (Single Page Application).
  - Incluye pantalla inicial de selección de carrera, dashboard, barra de navegación,
    tablas de materias, calculador de notas y modales interactivos.

• styles.css
  - Sistema de estilos responsivos optimizado para PC y teléfonos móviles.
  - Paleta cromática en Verde Marino (#0A4D40, #006654, #00897B) y Blanco.

• pensumData.js
  - Estructura y datos precargados con el Pensum Oficial UNEXCA.
  - TSU en Administración (110 UC) y Licenciatura (222 UC acumuladas).
  - Configuración inicial de materias de Informática.

• app.js
  - Lógica interactiva en JavaScript.
  - Gestión de LocalStorage, calculador de notas ponderadas (0 a 20 pts),
    conmutador de semanas A/B, filtros, modales y centro de notificaciones.

• database.py
  - Script en Python con base de datos relacional SQLite3 (sistema_universitario.db).
  - Crea tablas de materias, evaluaciones, horarios y notificaciones.

• server.py
  - Servidor backend API REST ligero en Python (sin librerías de terceros).
  - Servidor HTTP local en http://localhost:8000 y endpoints SQL.

• git-auto-sync.ps1  (PowerShell)
• git-auto-sync.bat  (Batch CMD)
  - Scripts de automatización para guardar commits y subir cambios a GitHub en 1 clic.

• .gitignore
  - Excluye archivos temporales para mantener el repositorio limpio y liviano.


--------------------------------------------------------------------------------
2. FUNCIONALIDADES INTERACTIVAS IMPLEMENTADAS
--------------------------------------------------------------------------------
[1] Selección Dual & Alternancia por Semanas:
    - Botones de entrada rápida a PNF Administración o PNF Informática.
    - Indicador superior de Semana A / Semana B con conmutación en tiempo real.

[2] Dashboard de Métricas de Créditos (UC):
    - Contador de UC acumuladas para TSU (Meta 110 UC) con barra de progreso %.
    - Contador de UC acumuladas para Licenciatura (Meta 222 UC) con barra de progreso %.
    - Conteo de materias en curso y materias por repetir.

[3] Gestión Dinámica del Pensum (+ Nueva Materia):
    - Vista organizada por Trayectos (1-1 al 4-2).
    - Filtros por estatus (En Curso, Aprobadas, Por Repetir, Intensivo, Pendiente Consulta).
    - Botones de edición e inserción para modificar nombres, códigos, UC y notas.

[4] Plan de Evaluaciones & Calculador de Notas:
    - Registro de evaluaciones por asignatura (Ponderación %, Nota 0-20, Fecha, Estatus).
    - Cálculo automático inmediato de nota acumulada sobre 20 puntos.

[5] Control de Consultas Pendientes:
    - Pestaña para revisar asignaturas pendientes por consulta oficial (Estadística,
      Expresión Oral, Marco Jurídico, etc.) y registrar la nota al ser publicada.

[6] Gestor de Horario Semanal (+ Agregar Clase):
    - Organización por días y aulas para Semana A (Administración) y Semana B (Informática).

[7] Alertas & Notificaciones (+ Nueva Alerta):
    - Creación de tareas, entregas de Proyecto (PSI II) y avisos de intensivo de verano.

[8] Control de Cambios & Sincronización Git:
    - Guardado local automático.
    - Exportación e importación de copias de seguridad en JSON.
    - Sincronización a GitHub desde la interfaz web o mediante scripts `.ps1` y `.bat`.
